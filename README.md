# THE LAST HOUR — LLM CTF

A Discord-based Capture The Flag game powered by an LLM.

## Author

- Herosmcx

## Versions

- `bot_r_th.py` — Thai Version
- `bot_r_eng.py` — English Version

## Features

- AI-powered NPC: OMEGA-7
- 60-minute gameplay
- Private player threads
- AI-driven conversations
- Hidden clues
- Flag submission system
- Thai and English versions

## Requirements

- Python 3.10+
- Discord Bot
- Google Gemini API Key
